# Konkan Railway Delay Analytics

## Objective

Analyze delay patterns of trains operating on the Konkan Railway corridor using one year of historical station-wise delay data.

## Datasets

- combined_delay.csv
- combined_schedule.csv
- train_details.csv
- station_full_names.csv

Source:

https://www.kaggle.com/datasets/rxydenxd/indian-railways-delay-dataset

## Workflow

1. Data Quality Analysis
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Machine Learning
6. Dashboard
